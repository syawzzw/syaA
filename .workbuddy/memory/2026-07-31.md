# 2026-07-31 工作日志

## Bug修复：URL协议头重复导致爬取失败
- **问题**：用户在 GUI 的"目标网站"输入框填入 `https://lw7f.srg3f.net`（带协议前缀），代码硬编码 `https://` 前缀再拼接域名 → 生成 `https://https://lw7f.srg3f.net/...` 导致 DNS 解析失败 `NameResolutionError: Failed to resolve 'https'`
- **根因**：L1798（普通爬取）、L1475（Cookie验证）、L2422（离线爬取）三处 URL 拼接都没有去除用户输入的协议前缀
- **修复**：在拼接前检测并去除 `http://` / `https://` 前缀（使用 `re.sub(r"^https?://", "", raw_host, count=1)`）
- **影响范围**：所有使用 `base_url` 拼接 URL 的地方（3处已全部修复）
- **用户操作**：GUI 输入框的提示文字建议更新，明确说明"仅填写域名，不要带 https://"
